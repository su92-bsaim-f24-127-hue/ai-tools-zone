## 2. Investigation: `blog/index.html` and `llms-full.txt`

A core requirement of this verification is to establish whether `blog/index.html` and `llms-full.txt` are generated files or tracked source files, and how they behave in the build:

### 2.1 `blog/index.html`
- **Git Tracking Status:** Tracked file in Git (`git ls-files blog/index.html` returns `blog/index.html`).
- **Generation Source:** Generated by `build_site.py` via `build_blog()` using data from `data/blog-content.json`.
- **Working Tree State:** Modified (`modified: blog/index.html`).
- **Content Changes:**
  - Added article card for `10 Best Cheap AI Tools for Students in Pakistan (2026)` with link `/blog/cheap-ai-tools-for-students-pakistan/`.
  - Added publication badge, reading time (9 min read), description, and WebP thumbnail.
  - Added new `@type: "ListItem"` entry into the `ItemList` structured data schema.
- **Finding:** `blog/index.html` is a generated artifact that is intentionally committed to Git so the static web host and repository stay in sync. It **must be staged**.

### 2.2 `llms-full.txt`
- **Git Tracking Status:** Tracked file in Git (`git ls-files llms-full.txt` returns `llms-full.txt`).
- **Generation Source:** Generated by `seo_pages.py` via `build_llms_full_txt(products, origin)` using `data/catalog.json`.
- **Working Tree State:** Unchanged (`git diff llms-full.txt` is empty).
- **Scope & Architecture:**
  - `llms-full.txt` is strictly defined as the *Full Catalog & Offer Specifications* for commercial products. It outputs:
    `# AI Tools Zone - Full Catalog & Offer Specifications`  
    `## Product Catalog (32 Seller-Listed Offers in PKR)`
  - It iterates over the 32 products in `data/catalog.json`. It does not ingest or manifest blog articles.
- **Finding:** `llms-full.txt` is regenerated deterministically during `build_site.py`. Because no commercial products were added or removed from `catalog.json`, its content is identical to the committed version. It does not contain blog articles by architectural design.
