# Homepage 3D logo render

Created using the built-in image-generation tool from `assets/brand-emblem.webp`.
The original favicon and small site identity marks are unchanged.

- Preserved source: `output/imagegen/hero-logo-3d-source.png`
- Desktop export: `assets/hero-logo-3d.webp`
- Mobile export: `assets/hero-logo-3d-mobile.webp`
- Export command: `python scripts/prepare_hero_logo.py`

The image is a 3D-rendered illustration with baked lighting, animated with gentle CSS perspective transforms. It is not a real-time 3D mesh or an editable CAD model. Alpha is preserved so the silhouette works in either site theme.
