ACCOUNT ACCESS TIERS

What do Private, Shared, Invitation and License Key access mean?

Private access gives you dedicated login credentials. Invitation access adds your personal email to a workspace seat. Shared access means more than one buyer uses the same account under fair-use rules. License Key access delivers an activation code for installed software.

Private access

Dedicated individual credentials with full profile privacy and separate login.

Invitation access

Personal email linked directly to a licensed team workspace or educational organization.

Shared access

Affordable communal profile access operating under fair-use guidelines.

License Key access

Digital activation code for permanent or subscription software installation.
